# AGENTS.md — `nexus`

## Overview
`nexus` is a unified multi-model CLI harness entrypoint, specialist intent router, and real-time delegation tree visualizer for OpenCode, local OpenAI-compatible HTTP servers, local Ollama, and an optional external CLI backend. It routes tasks across free and subscription OpenCode models (`opencode/*-free`, `opencode-go/*`), local HTTP backends, and an optional premium CLI while rendering a live hierarchical delegation tree backed by an append-only JSONL event bus (`~/.local/state/nexus/events.jsonl`). It also ships a Self-Improvement Memory (SIM) ledger and a Continual Recursive Self-Improvement (CRSI) outer loop.

## Architecture & Module Map
- `bin/nexus` (`~/.local/bin/nexus`): CLI entrypoint (`nexus` TUI on a TTY or REPL otherwise, `nexus tui`, `nexus --repl`, `nexus [--profile NAME] [--sticky] run [--think] [--no-fallback] [-f] [-o]`, `nexus council [--unified]`, `nexus watch`, `nexus routes [--validate] [--local]`, `nexus doctor [--prune-events]`, `nexus square`, `nexus sim ...`, `nexus evolve [--scope routes|prompts|full|polyglot] [--objective ...] [--profile NAME] [--explorer-route ...] [--parallel] [run|eval|challenge|suggest]`, `nexus profile [list|show|init]`, `nexus stats [--by profile|route|model]`, `nexus bench [--profiles ...]`). Subcommand `-q`/`-v`/`--no-color`/`-r`/`--dry-run`/`--profile`/`--sticky` use `default=argparse.SUPPRESS`. REPL defaults to Unified Entity Mode (`entity_history`, `/profile`, `/pin`, `/unpin`, `/mode`, `/stats`, `/think`, `/save`) while `--sticky`/`/mode sticky` preserves classic sticky route takeover.
- `nexus/entity.py`: Unified Entity Mode & Pluggable Profile Lab (`EntityProfile`, `list_profiles`, `load_profile`, `save_user_profile`, `resolve_profile_routes`, `build_handoff_context`, `compose_entity_prompt`, `build_synthesis_prompt`, `compute_performance_stats`, `render_stats_table`, `benchmark_profiles`, `render_bench_table`).
- `config/profiles/` (overridable via `~/.config/nexus/profiles/*.json`): Built-in configuration profiles — `default` (`entity`), `free-only` (`entity`, `$0` routes), `local-only` (`entity`, `@local` + `@ollama`), and `ensemble` (parallel internal seats synthesized into one voice).
- `config/routes.json` (overridable via `~/.config/nexus/routes.json`): Canonical declarative specialist routing table and quota-tier metadata (`FREE`, `GO`, `LOCAL`, `PREMIUM`), including `@refactor` (`opencode-go/kimi-k3.1-pro` fallback `opencode-go/qwen4-max`), `@reason` (`opencode-go/glm-5.3` fallback `opencode-go/qwen4-max`), `@local` (`openai-compat` on `127.0.0.1:8000`), `@ollama` (`ollama` on `127.0.0.1:11434`), `@premium` (optional external CLI on the `PREMIUM` tier), and 300s timeouts on heavy routes. `local`, `ollama`, and `premium` are `explicit_only`.
- `config/sim_policy.json` & `config/policies/{self_rewrite,polyglot}.json`: `ScopePolicy` inputs (`routes` default vs `full` harness edits vs `polyglot` `native/` edits). All policies inherit `IMMUTABLE_LOCKED_FILES`, locking `nexus/{sim,evolve,drops,assay,errata,contract}.py`, `config/sim_policy.json`, `config/policies`, `config/evals`, `tests`, `.git`, and `.env`.
- `config/evals/routing_benchmark.json`: Named two-split routing benchmark (`nexus-routing-v1`, `builtin:routing`) with disjoint `evolve_tasks` and `held_out_tasks`, expected routes, and `forbidden_routes` guards. Duplicate or overlapping task IDs are rejected at load time.
- `docs/sim-architecture.md`: Public engineering guide to the SIM schema, ten optimizer directives, three-tier transfer canon, consolidation lifecycle, improvement ladder (`prompt_tune -> profile_tune -> code_refactor -> polyglot_rewrite`), and `sim`/`evolve` CLI.
- `nexus/sim.py`: Self-Improvement Memory ledger (`SCHEMA_VERSION = "1.0"`, `DEFAULT_SIM_PATH = ~/.local/state/nexus/sim.json`, `NEXUS_SIM_PATH` override). Implements atomic load/save, transitive alias resolution, problem open/merge, outcome computation, append-only attempt recording, carry-forward chains, schema-break records, lossless compaction (`invariant_summary`, `model_notes`, `dead_ends`, `archived_attempts_count`), validation, prompt formatting, and a width-safe summary panel.
- `nexus/evolve.py`: CRSI outer loop. Holds `OBJECTIVES`, `IMPROVEMENT_LADDER`, `SCOPE_PRESETS`, ten canonical Proposer/Selector directives, four `PROACTIVE_RESEARCH_DIRECTIVES` (`R1`–`R4`), three transfer tiers, immutable locked-file defaults, `ScopePolicy` (`editable_files`, `editable_dirs`, `build_cmd`, `for_scope`), sandbox isolation (`build_sandbox_env` secret/egress guard + `_assert_sandbox_edit_integrity`), MAP-Elites/Pareto archive (`compute_pareto_front`, `update_pareto_archive` at `~/.local/state/nexus/pareto_archive.json`), GEPA `collect_trajectory_feedback`, `$0` `resolve_explorer_routes` + concurrent `--explorer-route`/`--parallel` exploration with user route override fallback in `_execute_route_span`, strictly disjoint `BenchmarkSpec` (`builtin:routing`, `builtin:core_quality`, `command`) and `EvalReport`, 1-hop JSON-repair retry, sandbox build verification (`_run_sandbox_build`), multi-axis `beats_baseline`, passive monitor (`detect_improvement_opportunities`), Proposer/Selector round, multi-round loop, and cold-start challenger. Held-out outcomes never enter prompts or the SIM.
- `nexus/errata.py`: Verbatim write-ahead complaint and false-pass ledger (`DEFAULT_ERRATA_PATH = ~/.local/state/nexus/errata.jsonl`, `NEXUS_ERRATA_PATH` override) joined by `trace_id`/`span_id` with zero LLMs on the interactive hot path. Exposes `record_erratum()`, `read_errata()`, `summarize_errata()`, `render_errata_report()`, and CLI/REPL/TUI `/erratum`.
- `nexus/assay.py`: Staged Assay verification receipts (`nexus-assay/v1`, SHA-256 byte-bound, returning `UNMEASURED` on empty stage sets and blocking later stages on failure), shadow-mode router calibration (`shadow_decisions.jsonl`, `summarize_shadow_log()`), and ISA markdown audit (`parse_isa_markdown()`, `render_isa_summary()`).
- `nexus/contract.py`: Machine-readable CLI contract (`nexus-cli/v1` 5-key JSON envelopes under `--envelope`, semantic exits `0/1/2/3/4/5`), `validate_trust_root()` nested-symlink guard, and `check_version_drift()` core-vs-docs drift detector.
- `native/nexus_fast.c` & `native/Makefile`: E8 compiled C99 hot path exporting `nexus_strip_ansi` and `nexus_find_tail_offset`; build with `make -C native` into `native/libnexus_fast.so` (git-ignored artifact).
- `nexus/native_bridge.py`: Optional `ctypes` bridge (`strip_ansi_fast`, `find_tail_offset_fast`, `native_available`, `native_status`) that loads `libnexus_fast.so` once under a lock. `NEXUS_DISABLE_NATIVE=1` (read per call) or a missing/broken library degrades every entry point to pure Python, so `nexus/visualizer.py::strip_ansi` (>=512-char payloads) and `nexus/events.py::read_events` (native tail-seek with seamless fall-through) never change behaviour. `tests/test_native_hotpath.py` asserts byte parity plus the E8 microbenchmark.
- `nexus/drops.py`: Sandboxed drop-folder delivery (`DEFAULT_DROP_DIR = ~/.local/share/nexus/drops/`, `NEXUS_DROP_DIR` override), native `SEND_FILE_TOOL_SCHEMA` for `send_file`, `write_drop_file()` (path/symlink/sync-metadata/`<=2 MiB` guards, auto `+x` on shebang/`.sh`, atomic `tempfile` + `os.replace`), `extract_code_block()`, and `save_text_artifact()` (which refuses `NEXUS_PROTECTED_PATHS`, an `os.pathsep`-delimited list).
- `nexus/events.py`: Lock-free `O_APPEND` JSONL telemetry emitter and reader (`~/.local/state/nexus/events.jsonl`) with tail-seek reads (`limit`, `trace_id`), `dry_run` tagging, automatic rotation above `2 MiB` (`AUTO_PRUNE_MAX_BYTES`), fallback-aware `merge_span_events()` updating model/route/backend/tier on fallback switches, and atomic `prune_events(keep_lines=2000)`. Spans record optional `profile` metadata under `_FIRST_WINS`. Evolve spans emit `evolve:round|propose|select` under the `ORCHESTRATOR` tier. `read_events(limit=...)` prefers `find_tail_offset_fast()` (E8) and falls through to the Python growing-window tail-seek on any native miss.
- `nexus/router.py`: Route loader, cached `opencode models` pin validator (`~/.cache/nexus/models.json`) checking routes + fallbacks + `decision_model` + `council_roles`, `_model_matches()` supporting `auto`/`auto/*` and `openrouter/openrouter/*` aliases, `resolve_route_api_key()` (`api_key_env`, `api_key_file`, `api_key`), Bearer-authenticated `probe_local_endpoints()`, direct-HTTP & shadow-mode `front_desk_decide()`, optional `fast_qa_route` bypass for short tool-free Q&A, and keyword/precedence intent classifier.
- `nexus/backends.py`: Subprocess and streaming HTTP (`ollama` NDJSON / `openai-compat` SSE) execution adapters with `--auto`, Bearer auth & `HTTPError` body capture in `_read_http_response()`, `classify_http_error()`, 3-scope lazy `RouteHealthTracker` + EWMA latency (`alpha=0.3`) + `reset_health_state()`, 1-hop OpenCode `fallback` AND cross-backend `fallback_route` (`_fallback_depth` bounded) with post-first-byte and `"auth"` guards, `_bounded_history()` deterministic `>240`-char old tool-output clearing + `_dedup_repeated_blocks()` `session-dedup`, entity `system_persona`/`handoff_context` injection (`compose_entity_prompt`), text/base64-image `_attachment_parts`, bounded native `send_file` tool-calling loop, `socket.shutdown()` instant HTTP cancel, partial timeout recovery, `_ThinkingStderrPrinter`, and `ExecutionResult.thinking`.
- `nexus/visualizer.py`: Pure ANSI wireframe delegation tree, routes table, and shared status vocabulary (`status_line()`, `format_duration()`, `format_tokens()`). Tier badges are `FREE`, `GO`, `LOCAL`, `PREMIUM`; premium span summaries use `premium_spans` / `non_premium_spans`. `strip_ansi()` short-circuits strings without escapes and routes only >=512-char payloads through `native_bridge.strip_ansi_fast()`.
- `nexus/sessions.py`: Persistent TUI state (`TuiSession` with `profile`, `entity_mode`, `pinned_route`, `last_route`, `active_route`, `active_backend`, `backend_session_id`, `TranscriptItem`, `tui_sessions.json` newest 30 kept, `tui.json` persisting `theme`, `sidebar_open`, `use_llm_decision`, `verbosity`, `profile`, `entity_mode`, `ui_mode`) via atomic `tempfile` + `os.replace`. `TuiSession.premium_spans` counts premium-tier spans and migrates the legacy field name on load.
- `nexus/tui/__init__.py`: TUI entrypoint exposing `NexusApp` and `run_tui()` (`verbosity=None`, `profile=None`, `entity_mode=None` inherit saved `tui.json` settings unless overridden).
- `nexus/tui/app.py`: `NexusApp` wiring sessions, Unified Entity Mode (`_active_profile_for`, `_is_entity_session`, `_run_unified_ensemble`, per-route `_route_sessions`, `/profile`, `/pin`, `/unpin`, `/mode`, `/stats`, `/sim`), root/child delegation spans (`front-desk`/`entrypoint`/`council`/`ensemble`), council budget enforcement, route-scoped `backend_session_id` isolation, local HTTP `history_messages`, `/think`, `/attach`, `/save`, active-session `/copy`, batched `transcript.mount(*widgets)`, premium-quota warnings, and live `verbosity` propagation.
- `nexus/tui/widgets.py`: Self-contained widgets including `ToolActivityGroup` (split O(1) `_refresh_title` vs dirty-gated `_refresh_body`, up to 16k-char thinking retention, `set_verbosity`), `AssistantMessageCard` (`set_thinking_progress`, debounced incremental `Markdown.append()`), `CouncilGridCard` (`update_seat_thinking`), `ComposerBox` (`think:` / `+file` indicators), and lazy `InspectorSidebar`.
- `nexus/tui/modals.py`: `ModalScreen` dialogs that `dismiss()` plain data — `RoutePickerModal` (route key or `RELEASE_KEY`; `r` front-desk, `v` live pin validation), `ThemePickerModal` (live theme preview, restores on `Esc`), `SessionPickerModal` (`("switch"|"new"|"delete", session_id)`), `HelpModal` (`SHORTCUTS` + `COMMANDS` two-column reference).
- `nexus/tui/themes.py`: The five dark themes (`nexus-charcoal` default, `oled-black`, `opencode-dark`, `github-slate`, `catppuccin-mocha`) in `NEXUS_THEMES` / `THEME_ORDER` / `DEFAULT_THEME`, plus `TIER_COLORS` / `TIER_LABELS`, `normalize_tier()`, `tier_color()`, `quota_markup()` and `quota_plain()`. Legacy tier aliases normalize to `PREMIUM`.
- `nexus/tui/styles.tcss`: Skeletal 0-gap stylesheet (docked tab bar, 1fr workspace, docked 44-col sidebar hidden by the `.hidden` class, composer, popup, modals). It references theme variables only, so it parses and renders under every theme.
- `tests/`: Automated `pytest` suite covering event bus concurrency, route validation, intent classification, tree visualization, streaming/cancellation, CLI subcommands, SIM schema/aliases/compaction, scope policy, the evolve/held-out firewall, and the cold-start challenger.

## SIM & CRSI Contract
- **Ledger shape:** `schema_version`, `interface` (`name`, `version`), `carried_from`, `schema_breaks[]`, `context` (`domain`, `policy_model`, `benchmark`, `created_at`), `aliases`, and `problems[]`. Each problem has `id`, `name` (root-cause hypothesis), `opened_round`, `tier`, `invariant_summary`, `model_notes`, `dead_ends`, and `attempts[]`. Each attempt is append-only and records `round`, `sample`, `action`, `accepted`, `backfilled`, `domain`, `what`, `files`, `predicted`, `fixed`, `missed`, `regressed`, `passed`, `total`, `score`, `policy_model`, `optimizer_model`, `benchmark`, `diff_ref`, and `ts`.
- **Directives:** All ten canonical directives are injected into every Proposer and Selector prompt. The full ledger is injected without truncation; root-cause attribution and pre-evaluation predictions are mandatory; failures, misses, regressions, and zero-fix attempts are retained as negative evidence; duplicates merge through aliases; security boundaries stay locked.
- **Firewall:** Only the evolve split is scored during optimization. `build_proposer_prompt` and `build_selector_prompt` reject any non-evolve baseline, a leak scanner checks every model-facing string for held-out IDs/prompts, and held-out tasks are evaluated exactly once per challenger run.
- **Transfer tiers:** `invariant` (Tier 1 durable invariants), `adaptable` (Tier 2 portable rationales that need new code), and `model_specific` (Tier 3 policy/domain-locked traps that should be pruned). Compaction prunes `fixed == []` zero-fix records only after distilling them into dead ends.
- **Lifecycle:** `carry_forward()` records the provenance chain; `compact_sim()` archives the raw ledger before distilling; unified synthesis pools active policy routes per round (`"{route}::{task_id}"`) instead of chaining models sequentially; `run_cold_start_challenger()` clones the evolved workspace and a pristine seed, runs both lineages, and compares held-out scores before recommending continuation or a fresh start.

## Output Contract & Verbosity
- **Streams:** `stdout` = model answer only; `stderr` = status lines, spinner, receipts and the delegation tree.
- **Status vocabulary** (`nexus.visualizer.status_line`): `◆` info, `▸` step/spawn, `✓` ok, `✗` fail, `⏱` timeout, `⛔` interrupted, `!` warn, `⠋` spinner, `cont` = iconless continuation line.
- **Receipts:** every `execute_route` outcome prints one line — `@route (in charge) · backend:model · [TIER] · 1.2s · 1.2k→340 tok · 3 tools · thought 1.5kc`, plus the first error line for `FAIL`/`TIMEOUT`/`INTERRUPTED`.
- **Verbosity:** `0` quiet (answer + errors only; `stderr` muted and TUI thinking collapsed), `1` default (status, live `┆` thinking stream on stderr, delegation tree, TUI thinking open by default), `2` verbose (adds decision rationale, intent, prompt preview, trace id, and cached token count). CLI `-q`/`-v` and REPL/TUI `/quiet` + `/verbose [0-2]` (TUI choice persists in `tui.json`). Subparser options for flags that also exist globally (`-v`, `-q`, `--no-color`, `--dry-run`, `-r`) use `default=argparse.SUPPRESS`.
- **Width discipline:** every renderer is exact-width at any terminal size — `render_routes_table` drops the PURPOSE column under 100 cols instead of squeezing all columns, `render_delegation_tree` ellipsizes and moves errors to a continuation row, `render_panel` truncates titles/footers with `…`, council cards are `render_panel` instances.
- **Robustness:** `_run_subprocess_bounded` joins reader threads before setting `stop` on normal exit so fast child stdout/stderr never drops buffered bytes, and kills the process group on timeout/cancellation; `_require_binary` preflights `opencode` and the configured external CLI before dispatch; HTTP streams abort quickly via `socket.shutdown()`.

## TUI Launch & State
- **Launch contract:** bare `nexus` starts `NexusApp` only when `sys.stdin.isatty()` **and** `sys.stdout.isatty()`; pipes, `cron`, captured output and `nexus --repl` use `run_repl()` from `bin/nexus`. If `from nexus.tui import run_tui` raises `ImportError`, the TUI path degrades to the REPL instead of failing. `nexus tui [--theme <name>] [--no-sidebar] [--dry-run]` starts the TUI unconditionally; `--theme` and `--no-sidebar` override the persisted values for that run without rewriting `tui.json`, and `--dry-run` pins keyword routing (`use_llm=False`) so no backend binary and no decision model are called.
- **Layout:** `#tab-bar` docked top, `#workspace` as a horizontal split of `#main-pane` (`#transcript` `VerticalScroll` + `SuggestionPopup` + `ComposerBox`) and the `dock: right` 44-col `#sidebar`, `#hint-footer` docked bottom. Zero gaps, one-cell borders, colour from theme variables only — no hardcoded palette in `styles.tcss`.
- **Adaptive width:** the sidebar auto-hides below 100 columns unless the user toggled it manually at that width (`_sidebar_manual_narrow`), and `CouncilGridCard` stacks from 3 columns to 1 below 110 columns (`set_stacked`). Both rules re-run on `on_resize`, not just on mount.
- **Streaming contract:** every widget that accepts streamed text stores raw markdown and pushes it into a debounced `Markdown.update()` (50 ms for answers, 80 ms for council seats). Unmounting mid-stream is normal (a session switch), so every query is guarded with `NoMatches`. All interpolated model/user text passes through `rich.markup.escape`.
- **Session state:** `TuiSession` holds `active_route`, `active_backend`, `backend_session_id`, `total_tokens_in/out`, `premium_spans` and a list of `TranscriptItem` (`kind`, `content`, `tools`, `thinking`, `trace_id`, `council_seats`, `ts`). `save_sessions` keeps the newest 30 by `updated_at`. Prompt history is the plain-text `~/.local/state/nexus/history` (last 500 lines, shared with the REPL). Config defaults mirror `DEFAULT_TUI_CONFIG` (`nexus-charcoal`, sidebar open, LLM decision, verbosity 1, `ui_mode: "webui"`) and are rewritten on every manual toggle. `NexusApp` launches in single-prompt WebUI layout (`ui_mode="webui"`) with `Ctrl+G` / `/ui [webui|cli]` / `--ui` toggling cleanly to CLI console mode and auto-swapping `gemini-dark` <-> `nexus-charcoal` when neither theme was customized.
- **TUI keymap:** `Enter` send, `Shift+Enter`/`Ctrl+J` newline, `Up`/`Down` history (or popup navigation), `Tab` accept suggestion, `Ctrl+G` toggle WebUI/CLI mode, `Ctrl+P` commands, `Ctrl+K` route picker, `Ctrl+L` session picker, `Ctrl+N` new tab, `Ctrl+Tab`/`Alt+Right` next tab, `Ctrl+Shift+Tab`/`Alt+Left` previous tab, `Ctrl+B` sidebar, `Ctrl+O` expand/collapse all tool groups, `Ctrl+T` theme, `Esc` cancel run or dismiss popup, `F1`/`?`/`/help` help, `Ctrl+Q` quit, double `Ctrl+C` quit. Actions live in `NexusApp.BINDINGS`, so a new binding belongs there, not in a widget.
- **Theme contract:** each theme defines the full variable set (`background`, `surface`, `panel`, `foreground`, `primary`, `secondary`, `accent`, `success`, `warning`, `error`, `border`, `border-blurred`, `footer-background`, `footer-foreground`) and is registered in `NEXUS_THEMES` + `THEME_ORDER` (`gemini-dark` adds Material 3 WebUI styling). A new theme must be added to both, or the picker and `--theme` resolution will not see it (an unknown `--theme` silently falls back to `DEFAULT_THEME`).

## Customization Contract
- `~/.config/nexus/routes.json` overrides the repository route table; keep machine-specific endpoints and hosts there, not in the committed defaults.
- `NEXUS_DROP_DIR` overrides `DEFAULT_DROP_DIR`; `NEXUS_PROTECTED_PATHS` (an `os.pathsep`-delimited list) blocks artifact writes into sensitive trees; `NEXUS_SIM_PATH` overrides the ledger location.
- `config/sim_policy.json` and `config/evals/routing_benchmark.json` are portable JSON. Any fork must preserve disjoint evolve/held-out IDs and keep security boundaries locked.

## TUI Performance & Styling Notes (Textual 8.2.8)
- Never compare `widget.styles.height` (a `Scalar`) to an `int`; track the last int in a field. The mistake forced a full reflow on every keystroke.
- Textual's `Button.-style-default:hover` beats plain `Button:hover` rules. Override it with `.-style-default` selectors, set `pointer: default`, and `active_effect_duration = 0` for borderless tab buttons.
- Keep timers on demand (composer ticker, spinners): start them only while busy and stop them on finish, cancel, or unmount.
- Read `events.jsonl` with the tail-seek `read_events(limit=N)`; never parse the whole bus on the UI thread.
- Show UI feedback synchronously on submit (`_begin_submission`) before `front_desk_decide` runs.
- Perf and animation guards live in `tests/test_tui_perf.py`.
